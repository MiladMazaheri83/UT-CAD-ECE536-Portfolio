# Computer-Aided Design of Digital Systems (CAD) - Portfolio

This repository hosts synthesizable digital design modules, CAD algorithmic tools, and micro-architectural implementations developed within the **Computer-Aided Design of Digital Systems (ECE536)** curriculum. 

Every design conforms to strict RTL synthesis guidelines, deterministic timing closure constraints, and automated verification practices.

## Course Overview
*   **Instructor:** Mostafa E. Salehi
*   **Focus:** Digital design methodologies, logic synthesis, test and verification, and FPGA architectures.

## Core Competencies Demonstrated
Throughout these modules, I successfully developed the ability to:
*   Decompose top-level systems into manageable, easily verifiable sub-units.
*   Perform microarchitectural exploration to balance price, performance, and power metrics.
*   Utilize standard EDA tool flows for hardware synthesis using Verilog & VHDL.
*   Develop comprehensive verification and test plans.
